Purpose
The purpose of this program is to analyze campus event data by filtering, sorting, and summarizing events. It displays attendance, capacity, attendance rates, and other useful information.
Setup
I set up the program by creating an array of campus events, with each event stored as an object containing its name, category, attendance, capacity, and status. I then wrote separate functions using methods like filter(), map(), find(), some(), every(), and reduce() to filter events, calculate attendance rates and totals, search for events, validate data, sort results, and display a final report.
Operation
The program filters events based on category and status, sorts them by attendance, and calculates totals and attendance rates. It also searches for a specific event and checks whether the event data is valid.
Limits
The program uses sample event data, so the results only reflect the records included in the code. Inputs must match the available categories, statuses, and event names to return the expected results.
